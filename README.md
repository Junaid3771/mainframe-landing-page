# Mainframe Landing Page

A Vite + React landing page for Mainframe with a cinematic, motion-driven hero section.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to Vercel

1. Push this repository to GitHub.
2. Import the repo into Vercel.
3. Set the framework to Vite and keep the defaults.
4. Use the project root as the app directory.
5. Deploy.

This project is configured as a standard Vite app, so Vercel should build it successfully with the default settings.
